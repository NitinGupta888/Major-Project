# 💻 Laptop Market Analysis

An interactive **Laptop Market Analysis Dashboard** built using Python, Pandas, Matplotlib, and Streamlit. The project analyzes laptop prices, brands, specifications, operating systems, ratings, and other market trends through an interactive dashboard.

## 📊 Project Overview

The dashboard allows users to explore laptop data using interactive filters and visualizations.

Users can filter the data by:

- 🏷️ Brand
- 🧠 Processor
- 💻 Operating System
- 🧠 RAM
- 🔍 Laptop Model

The dashboard automatically updates the displayed records, summary statistics, and charts based on the selected filters.

## 🚀 Features

### 🔍 Interactive Filters

- Select a laptop brand
- Select a processor
- Select an operating system
- Select RAM
- Search for a specific laptop model
- View the total number of filtered records

### 📊 Dashboard Summary

The dashboard displays:

- 💻 Total Laptops
- 💰 Average Price
- 💎 Highest Price
- ⭐ Average Rating

### 📈 Visualizations

The project includes the following charts:

1. 🏷️ Brand-wise Average Price
2. 💻 Operating System Distribution
3. 🧠 RAM vs Average Price
4. 🧠 Processor Distribution
5. 💎 Top 5 Most Expensive Laptops
6. 💰 Laptop Price Distribution
7. 💾 Storage Distribution
8. ⭐ Rating Distribution
9. 🏆 Laptop Count by Brand

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/your-username/Laptop-Market-Analysis.git
```

### 2. Navigate to the project folder

```bash
cd Laptop-Market-Analysis
```

### 3. Install the required libraries

```bash
pip install streamlit pandas matplotlib
```

### 4. Run the Streamlit application

```bash
streamlit run Laptop_Market_Analysis.py
```

The dashboard will open in your web browser.
